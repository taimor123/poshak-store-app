# Image prompts for Gemini

Save each result in `poshak-store-app/public/products/` using the file name shown, e.g. `noor-1.jpg`.
`-1` is the main image on cards; `-2` and `-3` appear in the product gallery.

**Every image:** portrait **3:4**, about 900×1200 or larger, JPG/PNG/WebP. If Gemini doesn't keep 3:4, add "vertical 3:4 aspect ratio" to the prompt again.

After all images are saved, run this in `poshak-store-apis`:

```
npm run db:attach-images -- ../poshak-store-app/public/products
```

---

**Style to keep consistent** (already included in every prompt below):
professional e-commerce fashion catalogue photo, plain warm ivory studio background, soft natural daylight, sharp focus, realistic fabric texture, no text, no watermark, vertical 3:4.
